<span class="line"><span style="color:#FEDE5D">@media</span><span style="color:#BBBBBB"> (</span><span style="color:#FF7EDB">min-width</span><span style="color:#B6B1B1">:</span><span style="color:#F97E72"> 640px</span><span style="color:#BBBBBB">) {</span></span>
<span class="line"><span style="color:#FEDE5D">  .gallery</span><span style="color:#BBBBBB"> { </span><span style="color:#72F1B8">columns</span><span style="color:#B6B1B1">:</span><span style="color:#F97E72"> 3</span><span style="color:#BBBBBB">; }</span></span>
<span class="line"><span style="color:#BBBBBB">}</span></span>
<span class="line"></span>
<span class="line"><span style="color:#FEDE5D">.tile</span><span style="color:#BBBBBB"> {</span></span>
<span class="line"><span style="color:#72F1B8">  break-inside</span><span style="color:#B6B1B1">:</span><span style="color:#FE4450"> avoid</span><span style="color:#BBBBBB">;   </span><span style="color:#848BBD;font-style:italic">/* 关键：别让一张图被拆到两栏 */</span></span>
<span class="line"><span style="color:#72F1B8">  margin-bottom</span><span style="color:#B6B1B1">:</span><span style="color:#F97E72"> 0.75rem</span><span style="color:#BBBBBB">;</span></span>
<span class="line"><span style="color:#BBBBBB">}</span></span></code></pre>
<p>原理是 CSS 多栏布局会把内容按<strong>高度</strong>尽量均匀地分配到各栏里 —— 这正好就是瀑布流想要的效果，不用自己算。</p>
<p>配上 Tailwind 就是：</p>
<pre class="shiki synthwave-84" style="background-color:#262335;color:#bbbbbb" tabindex="0"><code><span class="line"><span style="color:#36F9F6">&#x3C;</span><span style="color:#72F1B8">div</span><span style="color:#FEDE5D;font-style:italic"> class</span><span style="color:#B6B1B1">=</span><span style="color:#FF8B39">"gap-3 sm:columns-2 lg:columns-3"</span><span style="color:#36F9F6">></span></span>
<span class="line"><span style="color:#36F9F6">  &#x3C;</span><span style="color:#72F1B8">button</span><span style="color:#FEDE5D;font-style:italic"> class</span><span style="color:#B6B1B1">=</span><span style="color:#FF8B39">"mb-3 block w-full break-inside-avoid"</span><span style="color:#36F9F6">></span><span style="color:#FFFFFFEE">…</span><span style="color:#36F9F6">&#x3C;/</span><span style="color:#72F1B8">button</span><span style="color:#36F9F6">></span></span>
<span class="line"><span style="color:#36F9F6">&#x3C;/</span><span style="color:#72F1B8">div</span><span style="color:#36F9F6">></span></span></code></pre>
<h2 id="为什么不用-js-方案">为什么不用 JS 方案</h2>
<p>除了少写代码，还有一个不太被提起但很重要的好处：<strong>没有布局跳动</strong>。</p>
<p>JS 方案必须先渲染一遍、测量、再定位。用户看到的顺序是：</p>
<pre><code>先看到图片挤成一列  →  突然跳成瀑布流
</code></pre>
<p>慢一点或者图多一点的时候，这一下很明显。CSS 方案在首帧就是最终布局，因为它压根没经过"中间状态"。</p>
<h2 id="宽高比要提前写死">宽高比要提前写死</h2>
<p>有个前提：每张图必须知道自己的宽高比，否则占位高度是 0，图片加载完会撑开容器、把下面的内容推下去 —— 还是跳。</p>
<p>所以内容数据里老老实实记了尺寸：</p>
<pre class="shiki synthwave-84" style="background-color:#262335;color:#bbbbbb" tabindex="0"><code><span class="line"><span style="color:#BBBBBB">{</span></span>
<span class="line"><span style="color:#72F1B8">  "type"</span><span style="color:#BBBBBB">: </span><span style="color:#FF8B39">"image"</span><span style="color:#BBBBBB">,</span></span>
<span class="line"><span style="color:#72F1B8">  "src"</span><span style="color:#BBBBBB">: </span><span style="color:#FF8B39">"/media/photos/p11.webp"</span><span style="color:#BBBBBB">,</span></span>
<span class="line"><span style="color:#72F1B8">  "width"</span><span style="color:#BBBBBB">: </span><span style="color:#F97E72">1400</span><span style="color:#BBBBBB">,</span></span>
<span class="line"><span style="color:#72F1B8">  "height"</span><span style="color:#BBBBBB">: </span><span style="color:#F97E72">900</span></span>
<span class="line"><span style="color:#BBBBBB">}</span></span></code></pre>
<p>渲染时写成：</p>
<pre class="shiki synthwave-84" style="background-color:#262335;color:#bbbbbb" tabindex="0"><code><span class="line"><span style="color:#36F9F6">&#x3C;</span><span style="color:#72F1B8">button</span><span style="color:#FEDE5D;font-style:italic"> style</span><span style="color:#B6B1B1">=</span><span style="color:#FF8B39">"aspect-ratio: 1400 / 900"</span><span style="color:#36F9F6">></span></span></code></pre>
<p>容器的高度在第一帧就定死了，图片什么时候加载完都不影响布局。</p>
<blockquote>
<p>想让页面不跳，靠的不是"加载得快"，而是"提前知道自己长多高"。</p>
</blockquote>
<h2 id="视频也走同一套">视频也走同一套</h2>
<p>视频元素同样能设置 <code>aspect-ratio</code>，所以图片和视频混在同一个网格里完全不需要特殊处理。视频额外做了两件事：</p>
<ul>
<li>缩略图上 <code>muted loop playsInline</code>，鼠标悬停才 <code>play()</code>，移开就暂停并回到开头</li>
<li>列表里只加载元数据（<code>preload="metadata"</code>），不预加载整个视频文件</li>
</ul>
